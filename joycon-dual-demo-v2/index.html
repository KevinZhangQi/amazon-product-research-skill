Connection flow

  1. Pair Joy-Cons with the operating system over Bluetooth.
  2. Click Connect Joy-Cons and select one left plus one right Joy-Con.
  3. Wait until both controllers are marked ready.
  4. Click Start Round.

Keyboard fallback remains available for quick local testing.
